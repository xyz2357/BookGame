# 游戏总览（Pitch / Vision）

## 一句话定位

**用名著作为工具的章节式叙事冒险游戏。玩家在一座"活着的图书馆"里探索，用书本解决事件、做出选择，达成不同结局。**

## 核心体验

玩家走进一座异常的图书馆迷宫。背包里有几本书——每本书有一个名字、一句台词、几个 tag。

遇到事件时（一扇锁着的门、一个哭泣的小孩、一面诡异的镜子），玩家翻开背包选一本书"用"上去。系统根据这本书的 tag 和事件的需求决定结果：

- **不匹配**：失败或绕路
- **普通匹配**：成功通过事件
- **超级匹配**：某本书恰好戳中事件的精确点 → 大成功，触发隐藏剧情或获得特殊奖励

通关一章 = 完成一段故事。多个关键节点选择 + 超级匹配的触发，决定结局走向。

## 类型与参考

**类型**：叙事冒险 / 章节式分支叙事 / 文字驱动游戏

**参考坐标**：
- 《极乐迪斯科》——技能/选项驱动叙事（但更轻）
- 《80 Days》——分支极多的旅行式叙事
- 《Citizen Sleeper》——文字驱动 + 资源管理 + 多结局
- 《艾迪芬奇的记忆》——文学化章节叙事氛围

**不是**：杀戮尖塔类 deck-builder、roguelike、战斗游戏。**没有战斗系统。**

## 卖点

1. **文学皮肤**：所有书都是真实名著（已过版权期），玩家在游戏过程中会遇到《变形记》《罪与罚》《聊斋》《道林·格雷》等
2. **超级匹配的"哦——！"瞬间**：当玩家发现"用《变形记》对那只甲虫"会触发隐藏剧情时的惊喜
3. **轻量但有重量**：玩法简单（选书+选选项），但叙事和氛围有分量

## 范围（重要）

**第一章 demo 作为完整独立小品发布**。

- 流程时长：单次通关 30-45 分钟，全收集多周目 2-3 小时
- 工作量目标：6-8 周做完
- 平台：PC（Steam / itch.io）
- 单人开发 + AI 辅助代码

**不做**：roguelike 程序生成、战斗系统、多章节主线（先做 1 章验证）

## 美术 / 音乐基调

- **视觉**：黑白 + 一种点缀色（建议暗红或赭黄，"古旧图书馆"质感）
- **风格**：手绘/插画感，避免 3D 和像素
- **UI**：仿古书页风，重点烘托"翻书"的仪式感
- **音乐**：环境音为主（书页翻动、远处脚步、灯泡嗡鸣），少量低调钢琴/弦乐

## 项目阶段目标

1. **代码骨架**（当前阶段）——把核心系统跑通，能用占位文本走完一遍流程
2. **内容填充**——完整剧本、所有事件、所有书的设计
3. **美术 + 音乐**
4. **测试调整**
5. **发布**
