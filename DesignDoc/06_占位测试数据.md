## 初始游戏状态

游戏开始时玩家：
- 当前节点：`entrance`
- 背包：`[starter_handbook, metamorphosis, painted_skin]`（这三本是测试用的固定起手）
- flags：空
- visited_nodes：空

## 用这套数据能验证什么

按这套数据走一遍：

1. **正常路径**：在前厅拿到 `lin_letter` → 走主走廊 → 用 `metamorphosis` 触发**超级匹配**穿过铁门 → 到最深处用 `lin_letter` 给林 → **结局：真相**

2. **替代路径**：在前厅拿到 `lin_letter` → 走主走廊 → 用 `painted_skin` 普通匹配（[揭露/鬼怪] tag）穿过铁门 → 到最深处用手册 → **结局：沉默**

3. **失败路径**：用错的书撞铁门 → 卡住 → 这时验证"用错书时给玩家提示但不死锁"

跑通这三条 = 代码骨架完全可用，可以开始填真实内容了。
