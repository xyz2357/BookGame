# 第一章关卡内容设计

> 本文档列出第一章 demo 的所有内容设计：剧情大纲、节点、事件、书清单、超级匹配、结局。
> 
> **状态**：骨架已搭，**具体文本和细节待填充**。代码骨架阶段先用占位文本测试。

## 章节大纲

**标题**：底层书库

**主角**：图书馆新来的实习生（性别/姓名玩家可选或留白）

**入场情境**：
入职第三天，主管交代你下底层书库整理一些被退回的书。底层书库平时不开放给读者，你之前没下去过。主管说："今天就你一个人下去，别待太晚——上次的姑娘，林，就是从那里出事的。"她说完意识到失言，匆匆走开。

**目标**：
- 表面：完成整理工作
- 深层：弄清楚林发生了什么

**情绪基调**：
不是恐怖游戏。是**带不安感的文学冒险**——昏黄的灯、过老的书架、几乎听不见的声音。氛围向《艾迪芬奇的记忆》《Disco Elysium》靠。

**流程时长**：单次通关 30-45 分钟

## 关键节点选择（3 个）

### 选择 1：镜厅之选 [`mirror_choice`]
位置：镜厅
情境：镜中映出一个似乎是林的身影，正在向你伸手
- `reach_in`：把手伸进镜子 → 解锁后续节点 `mirror_world`
- `step_back`：后退离开 → 不解锁镜中世界，但保留普通路线

### 选择 2：老管理员的话 [`trust_old_librarian`]
位置：管理员办公室（事件触发）
情境：另一位老管理员告诉你"林是自愿离职的，别再追问"
- `trust`：相信，停止调查 → **直接触发结局 A**
- `doubt`：不信，继续 → 失去老管理员的协助（某些事件少一种解法）

### 选择 3：献祭抉择 [`final_choice`]
位置：最深处（章节最后）
情境：要继续前进，需要"留下一本书"
- `leave_starter`：留下入职书（情感代价低）→ 进入正常结局判定
- `leave_specific`：留下章内拿到的某本特定书（视具体哪本，触发不同分支）
- `leave_nothing`：什么都不留，硬走 → **结局 D 路线之一**
- `turn_back`：放弃前进，回头 → **结局 C：替代**

## 事件清单（约 15 个，待详写）

### 入口区
- E01：石阶上的尘（进入 `entrance` 时的氛围描述，无解法）
- E02：林的办公桌（在 `front_room`，拿到 `lin_letter`）

### 管理员办公室
- E03：老管理员的话（在 `admin_office`，触发 `trust_old_librarian` 选择）

### 主走廊
- E04：生锈铁门（解法：[力量]/[毁灭]/[开锁]/[智慧]，超级匹配 `metamorphosis`）
- E05：低语书架（书架在念什么——解法：[安抚]/[揭露]/[沉默]）

### 书架 A
- E06：错位索书号（解法：[整理]/[规则]/[智慧]，超级匹配 `madman_diary`？）
- E07：捡到一本书（无门槛，获得书）

### 书架 B
- E08：哭泣的小孩（解法：[安慰]/[家庭]/[童话]/[冷漠]，超级匹配 `crooked_field`）
- E09：捡到一本书（无门槛，获得书）

### 镜厅
- E10：镜中身影（触发 `mirror_choice` 选择）
- E11（镜中世界专属）：倒影中的林（解法：[镜子]/[双生]/[救赎]，超级匹配 `dorian_gray`）

### 后廊
- E12：坍塌的书架走廊（解法：[毁灭]/[共鸣]，超级匹配 `usher`）
- E13：黑暗的房间（解法：[火]/[勇气]/[揭露]）

### 禁区入口
- E14：一本"会读人"的书（核心剧情事件，多种解法对应不同结局路径）

### 最深处
- E15：林的真相 + 选择 3（`final_choice` 触发）

> 实际事件数最终可能在 12-18 之间。MVP 阶段先做完 6-8 个，跑通整体流程后再扩。

## 超级匹配清单（5 个）

| ID | 书 | 事件 | 触发效果（梗概）|
|---|---|---|---|
| `sm_metamorphosis_door` | `metamorphosis` | E04 生锈铁门 | "想象自己是甲虫"，无伤穿过，书发光 |
| `sm_crooked_child` | `crooked_field` | E08 哭泣的小孩 | 给小孩一只虫子，小孩破涕，给隐藏奖励 |
| `sm_dorian_mirror` | `dorian_gray` | E11 镜中倒影 | 让镜像替你承受某事，书发光 |
| `sm_usher_collapse` | `usher` | E12 坍塌走廊 | 让坍塌"完成"，开出新路 |
| `sm_read_the_book` | `the_book_that_reads_you` | E14 会读人的书 | 触发隐藏结局 D 路线 |

> 玩家在游戏里**不会被告知**"这是超级匹配"。结果文本会比普通解法更长、更有戏剧张力，玩家自己感觉得到。可以加一个隐藏统计在结局界面显示"你触发了 N 个共鸣"。

## 结局清单（4 个 + 兜底）

### 结局 A：安宁（priority 10）
**条件**：`trust_old_librarian == "trust"`

**文本**：
> 你回到地面，把工牌交还。前辈说得对——林只是离开了。
> 
> 那天晚上，你在公寓里听到一种微弱的声音，像是远处书页翻动……你打开窗，外面只有风。
> 
> 你以为故事就这样结束了。

### 结局 B：真相（priority 30）
**条件**：
- `trust_old_librarian == "doubt"`
- `flag: found_lin == true`
- `final_choice == "leave_starter"` 或类似

**文本**：
> 你找到了林。她变成了一本书——一本你能读懂的书。你抱着她回到地面。
> 
> 没人知道她去了哪里。但你知道。

### 结局 C：替代（priority 30）
**条件**：
- `trust_old_librarian == "doubt"`
- `final_choice == "turn_back"` 或选择留下

**文本**：
> 你没回去。
> 
> 第二个月，新来一位实习生。她在你的办公桌上发现一张纸条，上面写着："如果你看到这个……"

### 结局 D：读完（priority 100，隐藏）
**条件**：`super_match_triggered: sm_read_the_book`

**文本**：
> 你把那本"会读人"的书读完了。
> 
> 你合上它的时候，整座底层书库轻轻消失了。林从书架后走出来，对你点了点头。
> 
> "原来这里也可以是出口。"

### 兜底结局：未完（priority 0）
**条件**：（无）

**文本**：
> 你在底层书库里待了很久。
> 
> 有些事你没弄明白。但天色已晚，你该回去了。
