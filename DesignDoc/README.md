## 范围警戒线（重要）

每次想做新东西时，先问自己：

1. 这是 MVP 必需的吗？
2. 这能不能放进 V2 想法仓库？
3. 如果加这个，1-2 个月预算还够吗？

**默认答案是"放进 V2"。**
