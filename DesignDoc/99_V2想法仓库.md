# V2 想法仓库

> 第一章 demo **不做**的所有想法都记在这里。
> 不是放弃，是延迟——做完 MVP 后根据反响再决定优先级。

## 玩法系统类

### 容器+发掘机制
书拿到手不立刻全开放，要在图书馆里通过某种行为（阅读时间、主题契合事件、共读、朗读）逐步发掘里面的台词/能力。

**记录的原因**：增加进度感和长期游玩动力，但 MVP 阶段会过度复杂化。

### 书页可被永久撕除（损耗机制）
每本书有多张"页"，撕掉一页换强力效果或墨水。HP = 总页数。

**记录的原因**：原本设计的核心机制之一，但和"用书解决事件"的简化定位冲突。如果未来想加一层"书也是消耗资源"的张力，可以从这里捡回来。

### 战斗系统
回合制网格战棋 + 卡牌（台词卡）。
**完整设计已在前期讨论中沉淀，需要时可以拉出来用。**

### Deck-builder 模式
书 = 容器，台词 = 卡牌，进战斗洗进牌库。
**和上面战斗系统一起作为完整 V2 包**。

### 书页之间互相塞（嫁接机制）
《老人与海》的页插入《变形记》→ 变形效果持续翻倍。组合空间巨大，但平衡难度高。

### 书的"角色弧"
你打过《变形记》的甲虫事件之后，这本书的台词从"我必须消失"变成"我不再害怕"，tag 也微调。书本身在游戏过程中成长/变化。

**第一章可以小范围尝试**——比如某本书在触发超级匹配后，台词改变。MVP 不做。

## 内容扩展类

### 多章节主线
第一章发布后，根据反响开发第二章。第二章应该响应第一章的玩家选择——不同结局解锁不同的第二章。

候选章节方向：
- **东方厅**：聊斋、山海经、红楼为底子
- **镜中世界**：博尔赫斯式的镜子图书馆
- **审判厅**：陀思妥耶夫斯基/卡夫卡式道德困境
- **未来部**：科幻经典（注意版权年限）
- **儿童区**：童话经典作为底子，但有诡异变体

### 跨章节书架
玩家通关一章后，部分获得的书会留在"主书架"里，下一章可以选若干本带过去。这给玩家持续的收集和成长感。

### "罕见书"机制
某些书极难获得，每章只能拿到 1-2 本。它们的 tag 和超级匹配特别强，但稀缺。给硬核玩家的目标。

### 完整作家系列
不只是单本书，做整个作家的"作品集"作为收集目标——卡夫卡的《变形记》《城堡》《审判》《饥饿艺术家》全收集解锁特殊事件。

### 玩家可以"写"自己的书
游戏后期解锁一个机制：玩家根据自己的经历"写"一本书加入背包，自定义 tag。这本书的内容是基于玩家这局做过的事生成的。

## 系统功能类

### 笔记系统
游戏自动记录玩家的关键选择、触发的超级匹配、读过的台词。可以在主菜单查阅。
**MVP 不做**——但用于结局判定的"记忆"已经在 GameState 里有了，只是没做 UI。

### 多存档槽
MVP 单存档够用。多存档是后期需求。

### 章节回看
通关后可以重新读自己经历过的剧情节点，无视游戏推进。

### 全成就系统
触发 N 个超级匹配、解锁所有结局、收集所有书等。

### 本地化
所有 UI 字符串已集中在 `strings.json`，结构上支持本地化。第一版只做中文，反响好再做英文。

## 美术 / 表现类

### 翻书的物理动画
书在屏幕上真的"翻"，每张台词卡是真的"页"。质感大幅提升。

### 书的视觉成长
书在游戏中可以视觉变化——发光、变薄、变厚、染色。

### NPC 立绘
现在文档里的 NPC（林、老管理员）都是文字描述。可以加立绘提升表现力。

### 环境音和氛围乐
深度的音效设计（书架的低语、远处脚步、风声）。

### 配音
重要文本配音。但成本很高，慎重。

## 商业 / 社区类

### Mod 支持
因为游戏完全数据驱动，理论上玩家可以自己加书、加事件、加章节。开放 mod 接口能极大延长游戏寿命。

### 社区"超级匹配"挖掘
官方藏一些极隐藏的超级匹配，让社区挖。

### 创作工具
官方提供事件编辑器，玩家可以创作自己的章节分享。

## 探索性想法（不一定可行）

### "你正在被读"
某一刻游戏会暗示玩家：你也是一本书，也有人在读你。这是个 meta 层的设计，做得好会非常震撼。

### 跨章节书的自我意识
某本你从第一章带到第三章的书，会"记得"你在第一章用它做过什么，并据此影响事件结果。

### 联机/异步多人
你在某章的关键选择，会影响其他玩家的章节。每个人的书架"互相影响"。技术成本极高。

### 实时事件
现实中某天某月，游戏里某本书会"被读到"——比如鲁迅诞辰那天，《狂人日记》能触发额外效果。
