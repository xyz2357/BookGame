# 音频资源规格说明

所有音频文件放在本目录下，格式要求 **MP3**（兼容性最好）或 **OGG**（质量更好）。
文件名必须与下方列表一致，系统会自动加载。

## 音效 (sfx/)

| 文件名 | 触发场景 | 风格描述 | 建议时长 |
|--------|---------|---------|---------|
| `page_turn.mp3` | 进入事件、确认结果、翻页 | 纸张翻动声，轻柔、带一点纸张摩擦的沙沙声 | 0.5-1s |
| `book_select.mp3` | 在背包中选中一本书 | 轻轻抽出书本的声音，木架轻响 | 0.3-0.5s |
| `book_use.mp3` | 确认使用一本书 | 书本打开、书页展开的声音，稍有仪式感 | 0.5-1s |
| `move_node.mp3` | 移动到新节点 | 脚步声 + 门开/走廊回响，低沉的空间感 | 1-1.5s |
| `success.mp3` | tag_match 成功 | 轻柔的铃声或竖琴拨弦，温暖的正反馈 | 0.5-1s |
| `super_match.mp3` | super_match 触发 | 魔法共鸣声——从低频到高频的光芒涌动感，有回响，让人感到"这一刻很特别" | 1.5-2s |
| `fail.mp3` | default（miss）失败 | 沉闷的关门声或低沉的嗡鸣，轻微的失望感，不要太刺耳 | 0.5-1s |
| `hp_loss.mp3` | harsh 事件失败扣血 | 蜡烛熄灭的呼气声 + 低频共鸣，紧张但不恐怖 | 1-1.5s |
| `gain_book.mp3` | 获得新书 | 轻柔的光芒音效 + 书页翻动，收获感 | 0.8-1.2s |
| `ui_click.mp3` | 通用 UI 按钮点击 | 极简的点击声，不要太突出 | 0.1-0.2s |

## 背景音乐 (bgm/)

| 文件名 | 播放场景 | 风格描述 | 建议时长 |
|--------|---------|---------|---------|
| `menu.mp3` | 主菜单 | 安静的钢琴 + 环境音，神秘但不阴沉，像深夜独自走进一座老图书馆。偏慢节奏，适合循环播放 | 60-120s loop |
| `explore.mp3` | 节点探索（通用） | 低调的环境音乐，弦乐铺底 + 偶尔的钢琴音符，营造"在书库中行走"的氛围。不能太满，要给文字阅读留空间 | 90-180s loop |
| `tension.mp3` | harsh 事件 / 后期区域 | 在 explore 基础上加入不安元素：不协和音程、心跳般的低频脉动、偶尔的金属摩擦。紧张但可控 | 60-120s loop |
| `ending.mp3` | 结局画面 | 钢琴为主的抒情曲，有"故事落幕"的感觉。前 4-8 小节安静，随后缓慢展开，适合配合结局文字渐入 | 120-180s |

## 整体基调

- 这是一个"古旧图书馆"风格的文字冒险游戏
- 音乐不要太满、太吵——玩家大部分时间在读文字
- 参考氛围：《艾迪芬奇的记忆》的安静感 + 《Citizen Sleeper》的环境音乐
- 所有音效应该有"纸质/木质/老旧"的触感，避免电子感
